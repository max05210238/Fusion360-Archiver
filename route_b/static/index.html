5. Security & restore

How to restore later: downloaded files are .f3d (single design) and .f3z (assembly + all linked parts) — Autodesk's official archive formats. To restore, in Fusion open the Data Panel ▸ Upload and choose the file; it loads back as a fully editable design.
About your keys & permissions: the Client ID/Secret and login token are stored only on this computer (your home folder, never uploaded, never shared). The tool requests data:read data:create account:read — it reads/lists your files and uses data:create only because Autodesk's download API requires it to build the archive; it never edits, overwrites, or deletes your designs. Treat the Client Secret like a password — don't post or screenshot it. When you're done backing up, click below to delete the saved keys + token; for full safety also delete the app at aps.autodesk.com/myapps ↗ (that permanently revokes the keys).
